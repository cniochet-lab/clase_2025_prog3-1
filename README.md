# clase_2025_prog3-1
Este es un repo para la clase de programacion 3, tercer periodo del 2025

# Para clonar el repos utiliza
git clone https://github.com/cniochet-lab/clase_2025_prog3-1.git

# Para crear una nueva rama utiliza
git branch -b nombre_rama

# Para sumar todos los cambios para subir, utiliza
git add .

# Para crear un comentario a tu commit utiliza
git commit -m "mensaje"

# Para subir tus cambios utiliza
git push

# Para obtener los cambios de una rama utiliza
git pull origin rama

Donde rama debe ser el nombre de la rama que quiere obtener sus cambios
